# Disk Limpeza Total — Financeiro V1

Sistema responsivo com a identidade visual da Disk Limpeza Total.

Já inclui:
- login e criação de conta;
- dashboard;
- clientes;
- produtos e estoque básico;
- geração de vendas gravada no banco;
- contas a receber e atrasados;
- layout para celular e PC.

Para publicar e usar a mesma conta em vários aparelhos, esta aplicação precisa ser hospedada com banco de dados online. O código já está separado em API + interface para essa etapa.

Para teste local:
1. Instale Node.js 20+.
2. Rode `npm install`.
3. Rode `npm start`.
4. Abra `http://localhost:3000`.
